### 清洗规则（确定性，可重跑）

1. 去维基标记：`== 标题 ==`、`'''粗体'''`、`[[内链|显示]]` → 显示
2. 去引用/模板残留：`<ref>…</ref>`、`{{…}}`
3. 全角括号统一：`［］｛｝` → 半角后统一处理
4. 游离闭合括号清除：汉字段间孤立 `] }` 删除（不清正文）
5. 部件合字：`｛雝缶｝` → `〔雝缶〕`（保留字形，不补 `□`）
6. 段落按**原文换行**切分，不做自动断句（避免误句读）
7. 空段/导航行剔除，单章 <10ms

### ord 还原策略（按优先级）

1. 单章整本 → ord=1
2. 卷次合卷页 → 负 ord，移入附文折叠区
3. 附录/词表 → 负 ord
4. 同 ord 重复（異本）→ 保留最长者，其余负 ord
4.5. 消歧残片（标题被更长标题包含）→ 负 ord
5. 剩余兜底：同分组末尾 → id 邻居插值 → 正文末尾
6. 负 ord 唯一化：同档位按出现顺序 +1 错位，保证组内稳定排序

### 本轮修正的两个数据缺陷

- **韩非子 4 章 ord 撞值**（八姦/忠孝/揚權/合卷页20 同为 -2e9）→ 已错位为 -2e9 / -2e9+1 / +2 / +3
- **60 章数字标题**（`水經注/06`、`韓非子/20` 等）→ 取首块 `h` 标题重命名；其中 **21 个韩非子合卷页**（每页 5–7 千字、含多篇）改为 `韓非子/合卷页01·初見秦第一起` 形态，避免被误读为单篇
