# 维点图书馆原生 AI 古籍助理

## 消解 · 解构 · 建构 · 重构：四重论证、全球学术与技术前沿核查、技术选型与实现路径

> 文档性质：立项前的**判准论证**，不是需求文档，也不是实施方案。  
> 边界声明：本文只产出论证与可视化，**不修改任何代码、不合并任何分支、不启动任何训练**。所有技术结论均为「有条件绿灯」，绿灯的边界条件在第四章逐条列出。  
> 方法承继：延续本工作区《全球阅读平台深度论证：排名、消解与构建》的分维度判定法，以及《知识治理与文明跃迁概论》的知识治理四维结构（KGQF：获取 / 传播 / 验证 / 权力分配），不给出「可行 / 不可行」的单点结论。  
> 核查时间：2026 年 11 月。凡引数字均标注来源与可信层级，媒体披露与厂商自报数据在文末统一标注复核义务。

## 〇、判准先行：什么样的问题才配叫「可行性」

「开发一个 AI 古籍助理是否可行」是一个被问坏了的问题。它把**五类异质判断**压缩成一个布尔值：

| 维度     | 真正该问的问题              | 判据              | 常见误判            |
| ------ | -------------------- | --------------- | --------------- |
| 技术     | 哪些子任务已越过可用阈值，哪些没有？   | 分任务的公开基准与人类基线之差 | 用「大模型很火」代替逐任务评测 |
| 证据     | 每一条输出能否回溯到具体的叶、行、版本？ | span 级可回溯率、伪引率  | 把「附了链接」当作「有证据」  |
| 学术     | 系统是否保留异说、歧义与未尽之处？    | 多解保留率、专家盲评      | 把「流畅白话」当作「理解」   |
| 主权     | 语料、批注、未刊稿、解释权归谁？     | 数据分级、出网边界、可迁移性  | 把「本地部署」当作「知识主权」 |
| 经济与持续性 | 不靠资本补贴能否长期维护？        | 基座复用率、模型可替换成本   | 把「能跑起来」当作「能活下去」 |

**结论前置**：这五维不共用一条及格线。因此本文的答案是**分维度有条件绿灯**——绿灯只发给「最小可证闭环」，不发给「通用古籍问答」。

## 一、消解（Dissolution）：先把七个伪问题拆掉

消解不是否定，而是**取消问题的合法形式**。以下七个命题在当前语境中不是「错」，而是「不成其为问题」，继续回答它们只会把资源引向错误的战场。

### 1.1 消解「原生 AI」的实体化执念

「原生」暗示存在一种从零长出来的、专门为古籍而生的模型。**这个实体不存在，也不需要存在**。全球前沿的路径恰恰相反：古籍能力 = 通用开源权重 + 领域继续预训练 + 窄任务微调 + 外部证据约束 + 人类校勘制度。识典古籍（北京大学数字人文研究中心 × 字节跳动）的技术栈是 OCR + 自动标点 + 自动校勘 + NER + 豆包大模型答疑的组合，不是「古籍专用大模型」；浙江大学 WYWEB 基准上，表现最好的基线甚至是**通用 DeBERTa-base（Avg 75.9）**&#x800C;非专域模型 GuwenBERT-base（72.9）或 SikuBERT（73.7）。

> **被取消的问题**：「我们该不该自研古籍大模型？」  
> **替换为**：「哪些能力必须自有（语料、证据层、本体、校勘制度），哪些能力应当可插拔（模型、OCR、向量库）？」

这条消解直接决定了成本结构与知识主权：**自有的是治理层，租用的是算力层**。

### 1.2 消解「古籍 = 语料」的还原论

把古籍降为 token 流，是本域最昂贵的一次降维。上海方志数智化研究给出的判词极准：传统 OCR 遵循线性扫描，把双行夹注、眉批、图文绕排强行割裂，「字都在，但书没了」。古籍不是文本，而是**至少八层叠合的对象**（详见 2.1）。一旦压成纯文本流，眉批会被当成正文、注疏会被当成原作者之言、后人评点会被当成同时代史料——这些不是识别误差，而是**本体论层面的对象损毁**。

> 引申的名实学判词：语料只是「名」的表层；「实」（历史指称）与「证」（版本与图像锚）在降维中被同时抹除。以名代实、以证为无，是古籍 AI 的第一原罪。

### 1.3 消解「助理 = 问答」的功能执念

问答是知识交互中**最弱**的一种：它强迫多解收敛为单解，强迫不确定性收敛为语气，强迫过程收敛为结论。而古籍研究的核心动作是**并置、对勘、存疑、追溯**，恰恰是问答所排斥的。HistAgent（普林斯顿 × 复旦）在 HistBench 上以多智能体调度把 GPT-4o 的 18.60% 提升到 pass@2 36.47%——这个「接近翻倍」的成果，其绝对值仍在**三成上下**；它证明的是「工具编排有效」，不是「历史问答已可用」。

> **被取消的问题**：「怎么让 AI 把古籍问题答对？」  
> **替换为**：「怎么让 AI 把可争议的证据摆到位，并把判断权还给学者？」

### 1.4 消解「理解 = 白话翻译」的等值幻觉

翻译是八层对象中最浅的一层。WYWEB 的古汉语—现代汉语翻译（WYWMT）中，人类 BLEU 45.6，最佳基线 40.1——看似接近；但同一基准的 WYWRC（古文阅读理解）人类 80.0、最佳基线 45.1，**落差 34.9 分**。这说明模型在「换一种说法」上逼近人类，在「知道这句话从哪来、指什么、为何在此」上仍近乎失能。以翻译质量作为验收指标，会系统性地把项目验收引向最容易、最不重要的那一层。

### 1.5 消解「可行性 = 技术可行性」

古籍 AI 的失败几乎从不发生在推理阶段，而发生在**许可、署名与解释权**阶段。识典古籍有 6 万余名注册志愿者，2025 年完成约 2 万部、约 15 亿字的初步校勘（China Daily 2026-07）；这批成果的权属、署名、可再分发条件若不逐层标注，任何基于它的二次系统都建立在未清的地基上。同样，《中国图书馆学报》2025 年第 1 期指出，现有基于 BIBFRAME 的古籍知识模型未能把「作品 / 版本 / 单件」与「人物 / 地点 / 时间」清晰分离，导致每次更新都要全盘修改——这是**模型缺陷，更是治理缺陷**。

### 1.6 消解「拥有语料 = 拥有知识」

ctext（Chinese Text Project）已开放 3 万余部、50 亿字，并接入哈佛燕京图书馆 500 万页扫描；识典古籍已上线近 7 万部、月访问 240 万量级。在这样的供给密度下，**再建一个「书库」是负资产**。语料可采购、可抓取、可众包；不可购买的是「把每条断言锚定到版本与叶面、并让校勘结果可复利」的治理能力。维点图书馆的资产位不在「第 70001 部书」，而在**书与书之间、断言与证据之间、读者与判断之间的那一层关系场**。

### 1.7 消解「规模叙事」

延续本工作区既有批判：用户量不等于可持续，社交不等于粘性，统一订阅不等于价值对齐。对古籍 AI 而言，「覆盖部数」「问答次数」「日活」都是易于制造、难以转化为学术价值的指标。真正该被度量的是**可回溯率、多解保留率、校勘回流转化率**——即知识治理四维中「验证」与「权力分配」两维，而非「获取」与「传播」。

### 1.8 消解的综合

七个伪问题共享一个根源：**把「生成」当作知识工作的中心**。消解之后剩下的正当问题是：

> 在模型必然出错、且错得极其自信的前提下，如何设计一个**不依赖模型正确性**仍能产出可信知识、并让每一次人的判断沉淀为可复用资产的系统？

## 二、解构（Deconstruction）：对象、任务、证据、权力、失败模式

### 2.1 对象的八层解构

| 层       | 内容                | 数字化后的常见损毁        | 必须以什么标准保全                              |
| ------- | ----------------- | ---------------- | -------------------------------------- |
| L1 物质   | 纸、墨、装帧、虫蛀、修复痕迹    | 被裁切、被增强算法「美化」    | 原始影像不可变 + IIIF Image API               |
| L2 版本   | 底本、校本、刊刻、递藏、题跋    | 多版本被合并成「一个定本」    | 作品 / 版本 / 单件三层（BIBFRAME / LRM）         |
| L3 版面   | 叶、行、栏、双行夹注、眉批、朱墨  | 压成线性纯文本流         | TEI P5 + 版面层级标注                        |
| L4 文字   | 异体、俗字、避讳、繁简、缺损、衍脱 | 强制简化字归一，丢失考据线索   | 原字与归一字**双轨并存**                         |
| L5 句读   | 断句、分段、引语归属        | 多说话人 / 间接引语处引号错置 | 句读作为「可争议标注」而非事实                        |
| L6 训诂义理 | 词义、名物、典章、制度、度量衡   | 以今义律古义           | 时间切片 + 权威辞书对齐                          |
| L7 互文传承 | 用典、引书、注疏、接受史      | 被当作独立文本，来源链断裂    | 互文边 + 溯源（参照 BuddhaNexus / DharmaNexus） |
| L8 历史语境 | 人物、地理、职官、纪年、事件    | 同名异实、同实异名被错误合并   | CBDB 人物唯一 ID + CHGIS 时空框架              |

**关键**：L1–L3 是「证」，L4–L6 是「名」，L7–L8 是「实」。名实学在此获得工程含义——**任何输出若不能同时给出名、实、证三者，即为不合格输出**。

**这张表是整个选型的支点**：🟢 集中在「感知与标注」，🔴 集中在「语义与判断」。因此架构必须**把 AI 放在候选生成层，把判断权放在人和证据层**，而不是反过来。

### 2.3 证据链的解构：定义「可证单元（维点）」

一条可信的古籍断言不是一句话，而是一条链：

```
断言（claim）
  → 文本 span（起止字符，含原字/归一字双轨）
  → 句 / 行 / 栏 / 版面层级（TEI）
  → 版本标识（底本 / 校本 / 卷次）
  → IIIF Canvas + 图像坐标（可缩放、可比对）
  → 校勘记与异说列表（不合并）
  → 责任者与时间戳（人 / 模型 / 众包，含置信度与复核状态）
```

据此把「维点」定义为最小可治理知识单元：

`维点 = <断言 span, 指称实（实体 ID）, 证据锚（版本+叶+坐标）, 置信度, 多解谱系, 责任链, 演化史>`

GaRAGe 的结论在此是硬约束：模型会**过度概括**、会把事实归到错误来源、会在无证据时依然作答；2025 年最可靠的做法是 **claim-level / span-level verification**。而 NORG 的综述补充了一个反直觉的实证：模型在出错时反而更倾向使用「无疑 / 一定 / 确实」等强肯定措辞。**因此「语气克制」必须写成系统规则，不能寄望于 prompt 教养**。

### 2.4 知识权力与数据主权的解构

按 KGQF 第四维，须逐项追问「谁定义正解」：

1. **本体权**：谁决定「松江府」与「松江区」是延续还是断裂？谁决定某异体字归入哪个字头？2026 年《全球视野下的中国古籍数智化演进与未来趋势报告》明确指出，全球协同中本体异构突出，**缺乏统一的中国古籍顶层本体模型**。这既是机会窗口，也是权力真空——谁先建本体，谁就隐性定义了后世检索的语义边界。
2. **解释权**：AI 把三家校注压成一段通顺白话时，学术争议被静默删除。多解不是噪音，是资产。
3. **署名权与责任链**：众包校勘、专家复核、模型候选必须分层署名，否则错误无从追责，贡献无从累积。
4. **语料权属**：公藏影像、公有领域文本、机构授权、志愿者成果、未刊稿——五类许可状态必须**逐层登记，不得默认 CC0**。CC0 是承诺，不是对他人成果的推定。
5. **可迁移性**：本工作区既有结论「知识资产的可迁移性需提前规划」在古籍域同样成立；Kindle 式锁定在学术场景更致命，因为学者积累的是**判断，不是书签**。
6. **数据不出网**：沿用本项目一贯的知识主权约束，设三级分类——公开典籍 / 机构授权影像 / 私有未刊手稿。**私有层：不上传、不入训练集、不作为 few-shot 送往云端、不留第三方日志**；本地权重（Ollama / vLLM 运行开源权重，Qwen / DeepSeek / GLM 多为 Apache 2.0 / MIT）是首选路径。注意「open-weight ≠ open-source」：权重可下载不等于训练数据与配方公开，故仍须逐版本核验 LICENSE。

> 辩证点：「工具无感」是本项目的长期承诺，但**无感 ≠ 无痕**。工具应当隐去操作负担，绝不可隐去出处、责任与版本。一个让用户「感觉不到自己在查证」却又能一键展开完整证据链的系统，才是对的；一个让用户「感觉不到证据存在」的系统，是把治理责任悄悄转移给了模型。

### 2.5 代表性使用者的深描（拒绝扁平标签）

不做「学生 / 研究者 / 爱好者」这类人口学贴签，而按**与知识的关系**刻画三种主体：

- **以存疑为业的人**（版本目录 / 校勘学者）：他不缺答案，缺的是「这一判断依据哪个本、谁先提出、异说何在」。他最恐惧的不是 AI 答错，而是 AI 答得**太顺**——顺到他多年的存疑被抹平成常识。对他而言，系统的价值是**把争议原样端上来**，并允许他署名校勘记。
- **在断裂处工作的人**（跨朝代 / 跨地域研究者）：他的痛点是同名异实、度量衡与行政区划随朝代漂移。他需要的不是检索，而是**柔性对齐与时空切片**：让「明代松江府」与「现代松江区」既相关联又不被等同。任何刚性统一词汇的本体，都会毁掉他的研究对象。
- **为知识续命的人**（图书馆 / 知识治理者）：他关心的是二十年后这批校勘成果是否还能被读出、被导出、被他人接续。他对「模型换了怎么办」「平台关了怎么办」的敏感度，远高于对回答质量的敏感度。**对他而言，可迁移性就是学术伦理**。

这三类人的共同点：他们要的不是「更聪明的回答」，而是**不被剥夺判断权**。任何以「降低门槛」为名压缩可争议性的设计，都会精准地失去最有价值的用户。

### 2.6 失败模式清单（按危害等级）

| 失效              | 危害                    | 对冲                       |
| --------------- | --------------------- | ------------------------ |
| 伪造书名、篇名、引文      | 致命；GaRAGe / Humy 均有实证 | 断言须绑定已存在 span，否则硬拒答      |
| 把注疏 / 眉批当正文     | 致命；对象损毁               | 版面层级标签随文本流转，不可丢弃         |
| 异体 / 避讳字误归      | 高；考据线索灭失              | 原字与归一字双轨，归一结果标为「建议」      |
| 引语归属错置          | 高；《史记》《孟子》多说话人处已见     | 句读与引号标为可争议，交人工复核         |
| 时代错置、以今律古       | 高                     | 时间切片 + 朝代系数显式标注          |
| 多解压成单解          | 高且隐蔽                  | 多解并置为默认展示，不做合并           |
| 置信度倒挂           | 中；错误答案语气更强            | 模板层禁用强肯定词，强制列出依据与异说      |
| 悄悄吸收用户批注入训练集    | 中；侵犯知识主权              | 批注默认仅本地沉淀，显式授权方可他用       |
| 引文存在但不含该断言      | 中；「附链接」的假安全           | span-level 验证，不验 URL 存在性 |
| 模型升级导致证据层失效     | 中；长期维护风险              | 证据层与模型层解耦，模型可插拔          |
| 指标拜物教（问答量 / 日活） | 中；目标漂移                | 以验证维与权力维指标为主             |
| 语料许可未清即上线       | 致命；制度风险               | P0 阶段逐层登记，未清不入索引         |

## 三、建构（Construction）：理论基座、分层选型、全球先例矩阵

### 3.1 理论基座的三重映射

| 理论       | 核心命题                 | 工程映射（可写、可测、可审计）                  | 若缺失会怎样      |
| -------- | -------------------- | -------------------------------- | ----------- |
| **名实学**  | 名 / 实 / 证三元，以名代实即是伪知 | 每条输出须同时给出 span、实体 ID、证据锚；缺一即拒绝输出 | 变成流畅的臆造     |
| **道场学**  | 知识在读者—文本—模型—社群的互动中生成 | 并置 / 质疑 / 回流三类动作一等公民；批注与校勘沉淀为维点  | 变成一次性消耗的对答  |
| **维点理论** | 最小可治理单元 + 关系场 + 知识复利 | 维点 schema（2.3）、版本化、演化史、跨馆互操作     | 成果随会话蒸发     |
| **KGQF** | 获取 / 传播 / 验证 / 权力分配  | 四维权力度量（KGMI 思路），但不作用户激励          | 只优化获取维，治理失衡 |

**可证伪性声明**：名实学在此不是装饰性术语。它对应一条硬规则——「无三元组，不输出」。这条规则可编码、可单测、可审计；若最终系统允许无锚输出，则本次理论映射即告失败，应承认其为修辞而非架构。

### 3.4 选型的十条硬约束（绿灯的前置条件）

1. **不训基础模型**。自研只发生在窄任务微调与本体层。
2. **证据层自有，模型层可插拔**。换模型不得导致证据链失效。
3. **本地优先，最小外传**；私有未刊层零出网、零入库、零 few-shot 上云。
4. **AI 只出候选**。所有断言默认标注「待校」，人复核后才可升格。
5. **证据先于流畅**。宁可输出短而带锚，不要长而顺。
6. **拒答是一等公民**。无锚必拒，由系统规则执行，不交给模型自觉。
7. **多解不压缩**。异说并置是默认态，合并须显式署名。
8. **可回溯到叶 / 行 / 坐标**，不是「附了个链接」。
9. **用户批注不进训练集**，除非逐条显式授权。
10. **全链路开源可迁移**，导出格式不锁定；退出成本可估算。

## 四、重构（Reconstruction）：从「助理」到「知识治理基础设施」

### 4.1 产品重定义

> **不是**：一个更懂古文的聊天机器人。  
> **是**：一个 **可证、可校、可续、可共治的古籍知识场**——把每条断言拆成维点，把每次判断沉淀为资产，把解释权留在人手里。

**三柱门**（与 BrewCode-OS-1 的方法论同构，但语义重铸）：

| 柱     | 对象           | 核心动作     | 对应 KGQF 维 |
| ----- | ------------ | -------- | --------- |
| **典** | 影像、版本、文本、版面  | 呈现、对勘、锚定 | 获取        |
| **点** | 维点、图谱、证据链、异说 | 拆解、链接、校验 | 验证        |
| **问** | 追问、并置、批注、回流  | 生成、质疑、沉淀 | 传播 + 权力分配 |

关键在第三柱：**「问」的产出不是答案，而是新维点与新校勘记录**。这才使知识复利成立——否则每次对话都是消耗，而非积累。

### 4.2 架构重构（证据流优先于模型流）

```
[影像与版本层]  IIIF / TEI / 许可登记
        ↓ 保留版面语法，不压平
[感知候选层]   OCR / VLM / 手写 HTR  →  原字·归一字双轨
        ↓ 只出候选，标「待校」
[维点层]       名—实—证三元组 + 实体锚（CBDB/CHGIS）+ 时间切片
        ↓ 图与 span 同时可检索
[推理层]       LlamaIndex + GraphRAG（Local/Global）+ 混合检索 + rerank
        ↓ claim-level span 验证
[治理层]       证据卡 / 多解并置 / 规则拒答 / 置信度克制
        ↓ 人复核后才升格
[场层]         三栏并置 / 校勘回流 / 深链分享 / 版本化沉淀
        ↺──────── 回流为新维点，形成知识复利闭环
```

模型位于**候选层与推理层**，不在治理层。治理层由规则、本体与制度构成——这是整个重构的核心：**系统的可信度不依赖模型的正确率**。

### 4.3 分阶段实现路径（含「明确不做」）

| 期               | 目标             | 范围与交付                                                                                 | 验收硬指标                                               | **明确不做**                |
| --------------- | -------------- | ------------------------------------------------------------------------------------- | --------------------------------------------------- | ----------------------- |
| **P0 判准与盘点**    | 把地基查清          | 选 1 部典籍 + 1 个版本组；逐层登记语料许可；冻结维点 schema 与「可证单元」定义；建立评测基线（WYWEB 子集 + 专家 100 题盲评集）；产出终态线框 | 许可无未清项；schema 可单测；基线分数可复现                           | 不训练、不开发界面、不接第三方 API     |
| **P1 最小可证闭环**   | 证明「不靠模型正确也能可信」 | 单部典籍：IIIF 影像 + TEI 文本 + OCR/句读候选 + span 检索 + 证据卡 + 句级纠错回流 + 深链分享                      | 强制规则下**伪引率 0**；引文 100% 可回溯到叶/行/坐标；无锚必拒答；专家盲评「可证性」达标 | 不做白话翻译、不做开放问答、不做社群、不做图谱 |
| **P2 图谱化与版本对勘** | 让「实」可计算        | CBDB / CHGIS 对齐、时间切片、职官与度量衡换算、多版本差异召回、GraphRAG Local/Global                           | 实体链接准确率；跨版本差异召回率；相对纯向量基线 F1 提升（参照南农 +11 点的量级，须本地实测） | 不做义理生成、不做自动定本           |
| **P3 生成性道场**    | 让知识复利成立        | 多解并置、追问链、批注回流与署名、校勘记版本化、可拖拽 / 可缩放 / 沉浸全屏、二维码与深链                                       | 校勘回流转化率、多解保留率、KGMI 四维诊断值、退出成本可估算                    | 不把模型输出升格为定论；不做用户激励式积分   |
| **P4 联邦与共治**    | 从单馆到场域         | 跨馆不汇聚语料而互操作（IIIF / OAI-PMH / MCP）、本体共建、伦理公约（算法透明度 / 历史真实性 / 数字主权）                     | 跨馆互操作用例通过；治理规则可审计                                   | 不追求语料集中、不追求平台垄断         |

### 4.4 五维可行性判定（分维度，不给单点结论）

| 维度    | 判定                      | 边界条件                                               |
| ----- | ----------------------- | -------------------------------------------------- |
| 技术    | 🟢 **绿灯（限 P0–P1）**      | 只在 🟢 任务上自动化；🔴 任务永不自动定论；OCR/VLM 须本地复测             |
| 证据    | 🟢 **绿灯**               | 前提是 IIIF + TEI + span 验证 + 规则拒答四项同时落地，缺一转红灯        |
| 学术    | 🟡 **黄灯**               | 需至少一位版本目录 / 校勘学者参与 P0 定义判准；无专家即无绿灯                 |
| 主权    | 🟢 **绿灯（技术上）/ 🟡（制度上）** | 技术可本地闭环；语料许可与志愿者成果权属须逐层清厘，未清即红灯                    |
| 经济与持续 | 🟢 **绿灯（限复用路线）**        | 复用识典 / ctext / IIIF / TEI / 开源权重；若选择自建语料库与自研模型则转红灯 |
| 哲学正当性 | 🟡 **有条件**              | 仅当系统确实把解释权留给人、且「名—实—证」规则可审计时成立；否则只是给检索套了层哲学修辞      |

**总判定**：**有条件绿灯，且绿灯只覆盖「最小可证闭环」**。任何以「做一个能回答古籍问题的通用助手」为起点的方案，判为红灯——不是因为做不到，而是因为它在知识治理四维中只优化「获取」，并把「验证」与「权力分配」外包给了概率模型。

### 4.5 反论证与自我批判

**反论证 A：识典 7 万部、ctext 50 亿字已覆盖绝大多数典籍，维点是否多余？**  
正面回应：二者在「获取」维已达极致，在「验证 / 权力分配」维仍开放。&#x4F46;**「补空白」不是充分的正当性**——若无不可替代的验证机制与共治制度，维点只是把已有语料再存一份，属于重复建设，应主动否决。故 P0 必须产出可证伪的差异化判据，而非「我们更懂哲学」。

**反论证 B：GraphRAG 与证据卡会不会只是把信任从模型转移到图谱的技术性安慰？**  
会。GaRAGe 显示归因 F1 最高仅 58.9%、无证据时正确拒答 TPR 最高 31%；Humy 的 grounded pipeline 即便把历史推理从 29.6% 提到 58.2%，仍有 12.2% 捏造率与 0.17 条/答案的无支撑断言。**锚定降低幻觉，不消除幻觉**。因此必须加上人类校勘、署名与责任链——信任的最终落点是**可追责的制度**，不是任何技术组件。

**反论证 C：本地优先会不会导致能力落后于闭源前沿？**  
在**有档案可依**的任务上，证据质量比参数量更决定结果（Humy：接档案的小配置 58.2% > 裸奔的更强模型 31.0%）。但须诚实承认：超长上下文、复杂多跳推理、跨语言古典文献处理，本地小模型仍有上限。故架构保留**可插拔的云端推理**，但默认关闭，且私有层永不经过。

**反论证 D：知识复利与 KGMI 式指标会不会变成新的指标拜物教？**  
会，且这正是本工作区对「阅读金融化 / 刷时长」批判的同构复发。故规定：治理指标**仅用于内部诊断与系统自检，不得转为用户激励、排名或可视化勋章**。一旦指标进入激励层，用户会优化指标而非优化理解。

**反论证 E：名实学 / 道场学是否只是给工程套了一层哲学名词？**  
这是最该被保留的怀疑。检验方式只有一条：**「无三元组，不输出」是否真的写进规则、真的可单测、真的会拦下输出**。若拦不下，则本文第三章的理论映射应被判定为修辞，项目应回到纯工程论证，不必再借哲学之名。
