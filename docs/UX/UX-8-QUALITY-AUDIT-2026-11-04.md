# UX-8 交付等级评估：是否达到"国际一线成熟应用"标准

- 评估对象：UX-8（首屏引导 + 精选四栏 + 两条降级分支），提交 `85afb7cc`，线上 `dimensionscosmos.pages.dev`
- 评估时间：2026-11-04
- 评估方式：**实测**，不引用主观判断代替数据。指标由 `scripts/audit-ux8-quality.mjs` 采集（Edge headless + CDP，非估算），阈值对照 Google web.dev 与 W3C WCAG 2.2 官方口径。
- 一句话结论：**工程纪律与可复算验收达到甚至超过一线团队水准；产品可观测性与国内分发性能未达一线；前端代码本身在弱网弱机下已达标。**

## 2. 实测证据

### 2.1 Core Web Vitals（阈值：LCP ≤2.5s、CLS ≤0.1、INP ≤200ms，按 75 分位分端计算）

| 场景 | 首页 LCP | 首页 TTFB | 详情页 LCP | CLS | 请求数 | 传输字节 |
| --- | --- | --- | --- | --- | --- | --- |
| 线上 · 桌面（1280） | 1268ms | 670ms | 668ms | 0 | 5 | 21KB |
| 线上 · 移动（393，Slow 4G + 4x CPU）第 1 次 | 6496ms | 4667ms | 1660ms | 0 | 5 | 21KB |
| 同上 第 2 次 | 2648ms | 646ms | 1876ms | 0 | 5 | 21KB |
| 同上 第 3 次 | 3304ms | 1394ms | 1548ms | 0 | 5 | 21KB |
| **本地 dist · 移动（同节流）** | **2060ms** | **84ms** | 972ms | 0 | 5 | 44KB |

**判读（关键）**：同一份产物，本地弱网 LCP 2060ms（Good），线上同样条件 2.6–6.5s（Needs improvement → Poor）。差异全部来自**跨境到 Cloudflare 的边缘链路**，不是前端代码问题。CLS 恒为 0，说明首屏无布局抖动。

> 口径诚实说明：以上是**单次/三次实测**，不是 CrUX 的 75 分位现场数据。要把"Good/Needs improvement"当结论，需要 RUM（见第 5 节缺口 3）。

### 2.2 渐进增强（关闭 JS 后）

| 项 | 结果 |

### 3.1 与同类古籍 / 经典平台对比（编辑判断，非实测）

同类平台（Chinese Text Project、Perseus Digital Library、维基文库、各家古籍数字化库）的普遍形态是：重检索与全文对照、轻首屏引导；现代 Web 体验（响应式、可访问性、结构化数据、多语 hreflang）多为弱项。
本项目在**首屏引导、可访问性、渐进增强、多语静态化**四项上明显高于同类常态；在**全文检索、引用导出、版本校勘、账号与笔记体系**上落后（UX-7 待做，且账号/收藏尚未规划）。
结论：**同类领域内属"体验领先、功能未齐"**，不能称"同类领域最高"——检索与引用是古籍平台的立身功能，缺它就无法宣称领域顶端。

## 4. 阻断"极高等级"的硬缺口（按优先级）

| # | 缺口 | 影响 | 建议 |
| --- | --- | --- | --- |
| 1 | 国内链路性能（TTFB 0.6–4.7s 波动） | 直接吃掉代码侧全部性能优势；新读者首屏可能等 6 秒 | 自有域名 + 可国内直达节点/CDN；上线前加"三地 TTFB 中位数"门禁 |
| 2 | 无 RUM / 无错误监控 | 性能与错误只能靠人肉跑脚本，无法感知真实用户 | 接轻量 RUM（CWV 字段）+ 前端错误上报 |
| 3 | canonical / JSON-LD 缺失 | 多语站易被判重复内容；无结构化数据（书籍/章节） | 0.5 人日补 BaseLayout |
| 4 | 无 `prefers-reduced-motion` | 前庭敏感用户不适；一线标配 | 0.2 人日 |
| 5 | 无埋点 / 无 A/B | 首屏引导效果无法量化（三步条转化率未知） | 与 UX-7 一并规划 |

## 5. "达到国际一线"的可验证定义（把口号变成清单）

满足以下**全部**才可宣称"国际一线交付标准"：

1. CrUX/RUM 上 **75 分位**（分移动/桌面）LCP ≤2.5s、CLS ≤0.1、INP ≤200ms；
2. WCAG 2.2 AA 全量通过，且有自动化审计进 CI（axe 或等价规则集）；
3. 有 canonical、结构化数据、sitemap、hreflang、x-default；
4. 有错误监控与关键漏斗埋点（首屏 CTA 点击、三步条各步到达率）；
5. 有灰度发布与回滚路径；
6. 关键路径无 JS 可用（本项目已满足）。

当前进度：**第 6 项已满足，第 2/3 项接近（各差 1 子项），第 1/4/5 项未满足。**

## 7. 复算方式

```bash
node scripts/audit-ux8-quality.mjs                  # 桌面线上
set MOBILE=1 && node scripts/audit-ux8-quality.mjs  # 移动 Slow4G + 4xCPU
set SITE=http://127.0.0.1:8798 && set MOBILE=1 && node scripts/audit-ux8-quality.mjs  # 本地 dist 对照
```

输出 JSON 落在 `temp/ux8-quality-*.json`，指标全部来自真实浏览器 PerformanceObserver 与 computed style，不含估算值。
