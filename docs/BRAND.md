**论证对象**：定稿目录 7 个文件（白 / 白字生态绿 / 白字星穹蓝底 / 白字原木土色底 / 中文字体 / 中文字体一点红 / 英文字体）

**结论**：作为品牌标识体系 **成立**；直接用作应用图标 **不合格**，需补 2 个衍生版。

## 二、形态解析（客观结构，非阐释）

图形标识为**单色线性构成**，可拆为四个结构层：

1. **骨架**：左侧竖脊（宽约占内容宽 12%）与顶部横梁（高约占内容高 15%）相接，构成一个**左上封闭、右下敞开**的 L 形框。
2. **内容层**：框内 8 条横线，**右列 4 条为长线**（由 x≈37 延至右缘），**左内侧 4 条为短线**（x≈17–40），长短错落、行距均匀。
3. **收口**：左下角以一段**内凹弧线**收束，左边缘先内收至最窄（占宽 13%）再向左下外扩，形成斜切轮廓。
4. **负空间**：右侧完全留白，无边框闭合。

**结构判读**：这是一本**侧立方书**的抽象——竖脊为书脊，顶梁为书口上缘，内部横线为**书页层叠的页边纹**，左下弧线为**翻页起点**，右侧敞开表示"未写完/向未来延展"。与目录内 `设计素材/打开的书页.png`、`字体/图01.png`（手写"图"字，比例 0.78，与本图 0.77 高度吻合）互为印证。

> 若你的原始释义与此不同，以你的原始释义为准——但上述结构是像素层面的既定事实，改述不影响后面的量化结论。

## 三、寓意论证

### 3.1 结构寓意：三个可读层

| 读解 | 成立度 | 说明 |
|---|---|---|
| 书脊 + 页边纹 | **强** | 竖向书脊与横向页纹是出版物的原型词汇，跨文化可读 |
| 书架 / 索引行 | 中 | 长短错落的横线亦可读作目录条目，呼应"知识索引" |
| 图（字形抽象） | 中 | 与 `字体/图01` 比例吻合，"图"即"图书馆"的字眼 |

三者不冲突，反而构成"**从一本书 → 一排书 → 一座馆**"的递进，这正是图书馆标识最需要的那层意思。

### 3.2 色彩寓意：四色即四重空间

这套配色不是随便选的四个色，而是**项目自身的空间叙事**：

| 色 | 对应空间 | 语义 |
|---|---|---|
| 星穹蓝 #003048 | 天穹 / 宇宙 | 英文名 *Dimensions Cosmos*（维度·宇宙）的直接翻译，主色当之无愧 |
| 生态绿 #84A890 | 田野 / 千湖 | 生态图书馆、渔院丹江千湖计划的在地性 |
| 原木土 #9C6C48 | 原木 / 夯土 | 书式民宿、屋顶菜园、乡村院落的材质记忆 |
| 一点红 #E41824 | 印章 / 点睛 | 唯一的暖色高亮，中国印记 |

**这是这套标识最有价值的地方**：四色各自承载一个真实空间，而不是设计师的配色偏好。品牌延展时不需要再编故事。

### 3.3 "一点红"的成立性

全稿只允许一处红，且红点落在"**点**"字上——语义与字形双重锁定"点睛"。这是低成本、高识别的手法，且**天然可拆**：中文字标整体可用，红点可单独作为"正在阅读"的状态标记、加载动画、签到印章。

## 四、国际化论证

### 4.1 分层的可迁移性

| 层 | 跨语言可读性 | 说明 |
|---|---|---|
| 图形标识 | **高** | 无文字，书脊+页纹是普适符号，任何语种都读得懂 |
| 英文字标 | 中 | 语义直译（Dimensions Cosmos Library），但**过长** |
| 中文字标 | 仅中文圈 | 5 字 3.82:1，无法独立出海 |

### 4.2 硬伤：英文名长度

英文字标宽高比 **10.74:1**。这个比例意味着：

- 放进 512×512 应用图标 → 字高只剩 **48px**，远低于可读下限；
- 放进应用商店截图标题位 → 必须缩到 60% 才放得下，实际阅读高度约 18px；
- 用作浏览器标签页 favicon（16px）→ **完全不可读**。

**结论**：英文长名只适用于**页脚、封面、印刷**等横向大幅面场景，**不得用于图标与商店头图**。

### 4.3 已有解药

目录内已存在 `维点图书馆logo（DCL）.png` 与 `DimensionsCosmosLibrary` 字体族——**DCL 缩写方案已经做过**。国际化落地的正确分级是：

```
图标层   →  纯图形（无字）
商店层   →  图形 + DCL 三字母
封面层   →  图形 + 中文五字 或 英文全称横向
页脚层   →  英文全称 + 中文全称并列
```

不需要重新设计，只需要**把已有素材按层分配**。

## 五、适用性论证（硬指标）

### 5.1 对比度（WCAG 2.1，实测）

| 组合 | 对比度 | 等级 | 可用性 |
|---|---|---|---|
| 星穹蓝底 + 白字 | **13.50:1** | AAA | 主推组合，正文级安全 |
| 生态绿底 + 深蓝字 | 5.27:1 | AA | 绿底必须换深色字 |
| **生态绿底 + 白字** | **2.56:1** | **不合格** | 现稿即此组合，**不达标** |
| 原木土底 + 深蓝字 | 3.07:1 | AA-Large | 仅限大字/图形 |
| 原木土底 + 白字 | 4.40:1 | AA-Large | 仅限 24px 以上 |
| 一点红底 + 深蓝字 | 2.94:1 | 不合格 | 禁止 |
| 一点红底 + 白字 | 4.59:1 | AA | 可作小面积点缀 |

**必须整改**：`白字生态绿` 版（2.56:1）在正文尺寸下不可用。两种修正：
- ① 绿底改深蓝字（5.27:1，唯一改动是把白换成 #003048）；
- ② 生态绿加深至 #5E7F6C 级别，再配白字。

推荐 ①——不动色值，只换前景，母版零风险。

### 5.2 maskable 安全区（PWA / Android 图标生死线）

Android 自适应图标与 maskable PWA 图标，会把图裁成**居中直径 80% 的圆**。

实测本图形：
- 内容框 y 到 389（占高 **87%**），x 到 **342**（占宽 77%）；
- 圆心 (223,223)，安全半径 178.4px；
- 图形最下缘 y=389 处，允许的 x 范围仅 **[158, 288]**；
- 而底部横线**延伸至 x=342**，**超出安全边界 54px**。

**结论：现有图形标识直接导出 512 maskable，右侧横条会被切掉一截。**

整改只需一步：新增"安全区版"——把图形整体缩到画布 **60%** 并居中，四边留透明/纯色边距。这一版**只用于图标**，不影响任何现有宣传物料的用法。

### 5.3 小尺寸辨识

| 尺寸 | 现状 | 结论 |
|---|---|---|
| 512 / 192 应用图标 | 清晰 | 可用（需安全区版） |
| 64px | 骨架+长横仍可辨 | 可用 |
| 32px favicon | 细横线与页纹间空隙 <1px，**糊成一片** | 需简化版 |
| 16px | 不可辨 | 需极度简化版（仅骨架） |

**结论**：favicon 不能直接缩，必须出**去细节版**（删内部分隔横线，仅保留 L 形骨架 + 2 条主横线）。

### 5.4 单色 / 反白能力

已具备：`维点图书馆（白）.png` 为纯白单色（#FCFCFC，透明底 58%），可直接用于深色底、烫金、丝印、激光雕刻。**这一项合格，且很多品牌在这一步翻车**——你的定稿群里已经备好了。

## 六、总判定与整改清单

### 6.1 判定

- **寓意**：成立。四色叙事扎实，结构递进清晰，"一点红"语义闭环。
- **国际化**：图形层成立，字标层需分层使用，长英文名下沉到页脚/印刷。
- **内涵**：成立。唯一高亮 + 唯一暖色，克制且有余地。
- **适用性**：**品牌物料合格，数字应用不合格**。三处硬伤：maskable 越界、绿底白字对比度不足、favicon 细节糊。

### 6.2 整改清单（全部为衍生，不改母版）

| # | 事项 | 优先级 | 状态 |
|---|---|---|---|
| 1 | 出 maskable 安全区版（图形缩至 52% 居中） | P0 | **已完成**，实测最远点 164.6px < 安全半径 204.8px |
| 2 | 出 favicon 简化版（16/32px，加粗笔画补偿） | P0 | **已完成** |
| 3 | 生态绿底版本改深蓝前景字 | P1 | 待定（需你拍板，见第八节） |
| 4 | 定 DCL 三字母图标版（已有素材，确认选用） | P1 | 待定 |
| 5 | 中文字标固定为唯一主字标，英文全称仅横向使用 | P2 | 本规范已约束 |

### 6.3 已落地到 PWA 底座的改动

| 项 | 原状 | 现状 |
|---|---|---|
| 应用图标 | 深蓝底 + 黄色占位符号（黄色不在品牌色系内） | 星穹蓝底 + 白色正式标识，图形占高 78% |
| maskable 图标 | 同上，且未校验安全区 | 图形占高 52% 居中，通过 80% 安全圆校验 |
| favicon | 占位 | 已按正式标识重制，16/32 加粗补偿 |
| theme_color | `#f7f2e8`（与站点底色同，无品牌感） | `#003048`（星穹蓝，与图标底色一致） |
| background_color | `#f7f2e8` | 保持 `#f7f2e8`，与页面底色一致，避免启动白闪 |

`theme_color` 与 `background_color` 分工：前者是**身份色**（状态栏、图标底），后者是**界面色**（启动屏、页面底）。两者不必相同，混用会导致启动闪白或状态栏突兀。

## 七、标准色系（本次定型）

### 7.1 色板

| 角色 | 名称 | HEX | RGB | HSV | 用途 |
|---|---|---|---|---|---|
| **主色** | 星穹蓝 | `#003048` | 0, 48, 72 | H200 S100 V28 | 品牌底色、正文墨色、PWA theme_color、应用图标底 |
| **辅助色** | 生态绿 | `#84A890` | 132, 168, 144 | H140 S21 V66 | 生态/田野板块、次级强调、图表第二序列 |
| **辅助色** | 原木土 | `#9C6C48` | 156, 108, 72 | H26 S54 V61 | 民宿/原木/乡村板块、暖色区隔 |
| **点缀色** | 一点红 | `#E41824` | 228, 24, 36 | H356 S89 V89 | 唯一高亮：红点、印章、状态标记、CTA |
| **中性色** | 纸白 | `#FCFCFC` | 252, 252, 252 | — | 反白字、浅底、留白 |
| **中性色** | 墨黑 | `#1C1C1E` | 28, 28, 30 | — | 长文正文（白底时优先于星穹蓝） |

### 7.2 使用配比

```
主色 60%  ·  辅助色 25%（绿:土 ≈ 3:2）  ·  纸白/留白 10%  ·  一点红 5%（上限）
```

**红线**：一点红面积**永不超过 5%**，一旦超过就从"点睛"退化为"廉价"。这是这套体系唯一需要死守的规则。

### 7.3 不可用组合（明令禁止）

| 禁止 | 原因 |
|---|---|
| 生态绿底 + 白字 | 2.56:1，不达标 |
| 一点红底 + 深蓝字 | 2.94:1，不达标 |
| 一点红作大面积背景 | 破坏点睛逻辑 |
| 四色同时平铺 | 无主次，识别度归零 |
| 图形标识拉伸变形 | 母版比例 0.77 为设计锁定值 |
