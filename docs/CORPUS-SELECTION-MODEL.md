# 古籍筛选模型 v1.0

> 状态：v1.0 定稿（2026-11-01）。本文件是**扩容选书的唯一规则来源**，任何候选书目的入库结论都必须能追溯到本文的维度定义与锚点表。
> 复算命令见 §7；数据文件见 §6。

---

## 1. 宗旨与由此推出的三条硬约束

宗旨：**让每一位读者提升认知**（不是收藏古籍、不是做全集）。

由宗旨直接推出三条硬约束，用于砍掉"名气大但对认知无用"或"认知有价值但读不下去"的选项：

- **约束 A｜可读完**：单部正文 1 万–200 万字。低于 1 万字不足以形成认知冲击（单篇可入"选读"而非"入库"），高于 200 万字在当前阅读器里无法闭环（《二十四史》级别只做选本或分卷）。
- **约束 B｜可解释**：必须有历代注疏或现代研究支撑，否则 AI 导读只能重复原文，不产生增益。
- **约束 C｜可核验**：底本来自公有领域（维基文库 / CTEXT / 正统道藏等），不得使用版权不明文本。

## 2. 评分维度与权重

综合分 = Σ(wᵢ × Dᵢ)，每维 0–5 分，满分 5.0。

| 代号 | 维度 | 权重 | 它真正在问的问题 |
|---|---|---|---|
| D1 | 认知增益 | 0.30 | 读完它，读者的**思维方式**会不会被改造？ |
| D2 | 思想内涵深度 | 0.25 | 它能否被反复读、被反复解释？ |
| D3 | 全球影响力 | 0.20 | 汉文圈之外，它是否被真实阅读与引用？ |
| D4 | 流通程度 | 0.15 | 读者今天能不能顺利拿到并读下去？ |
| D5 | 话题度 | 0.10 | 它是否还在当代公共讨论与再创作中活着？ |

权重理由：D1+D2 合计 0.55，明确"认知优先于名气"；D3 占 0.20 是因为本题要求纳入全球影响力，但不能让它压过认知价值（否则会选出"被翻译得多但读完无所得"的书）；D4 是可用性门槛的软化版本，D5 只做微调（话题度天然易被短视频放大，权重刻意压到 0.10）。

### 2.1 D1 认知增益（0.30）

判定问法：**这本书提供了什么可以被搬走的思维工具？**

| 分 | 锚点 |
|---|---|
| 5 | 提供一套**可迁移的元框架**，能跨领域复用（例：周易的变易/时位观、孙子的"形—势—虚实"、庄子的齐物与相对化、韩非的"二柄—参验"） |
| 4 | 提供强解释力模型，但迁移需读者的领域桥接（例：资治通鉴的治乱周期、齐民要术的系统农学观） |
| 3 | 提供稳定的领域内方法论（例：史通的史学批判纲领、文心雕龙的文体论） |
| 2 | 主要是知识信息与经验条目，方法论成分弱（例：梦溪笔谈、天工开物） |
| 1 | 纯资料汇编、纯规范训诫，无可迁移结构（例：部分蒙书、类书） |

### 2.2 D2 思想内涵深度（0.25）

判定问法：**它有没有"解释空间"，能否撑起多视角导读？**（这也是本项目 9 种导读方法能否跑得动的前提）

| 分 | 锚点 |
|---|---|
| 5 | 历代注疏 ≥3 家且争论持续至今；核心命题开放、可反读（例：老子、庄子、周易、论语） |
| 4 | 注疏 2 家以上，主旨有争议但边界清晰（例：孟子、荀子、墨子） |
| 3 | 注疏有限、主旨明确，深度来自体系而非歧义（例：孙子兵法、韩非子） |
| 2 | 主旨单一、以叙事或条目为主，但含可提炼的判断（例：世说新语、搜神记） |
| 1 | 操作手册/清单式，几无解释空间（例：三十六计、茶经） |

### 2.3 D3 全球影响力（0.20）

判定问法：**汉文圈之外，它被真实翻译、引用、教学的程度。**

| 分 | 锚点（满足其一即可） |
|---|---|
| 5 | 译本 ≥20 语种，或进入世界性通识课程/机构长期采用（例：论语、老子、孙子兵法） |
| 4 | 译本 10–19 语种，或有两个以上文明圈的持续研究传统 |
| 3 | 译本 4–9 语种，主要见于东亚与汉学界 |
| 2 | 译本 1–3 语种，限学术圈 |
| 1 | 基本限于汉文圈内部流通 |

**核验规则**：D3 不是可以"凭印象"打的维度。每个分数必须带一条可引用来源（译本语种数、机构采用事实、研究综述），写入 `corpus_scores.csv` 的 `d3_evidence` 字段。无来源时该行置 `UNVERIFIED`，**不计入排序**，只作待核验队列（见 §7.3）。

### 2.4 D4 流通程度（0.15）

由两个可核查子项合成，避免主观：

```
D4 = (可得性 + 篇幅友好度) / 4 × 5
```

| 子项 | 取值 |
|---|---|
| 可得性 | 2 = 维基文库/CTEXT 有完整可商用全文；1 = 有全文但需校勘/拼合；0 = 仅存残卷或需商业底本 |
| 篇幅友好度 | 2 = ≤5 万字；1 = 5–20 万字；0.5 = 20–60 万字；0 = >60 万字 |

（例：论语约 2.3 万字、全文可得 → (2+2)/4×5 = 5.0；资治通鉴约 314 万字、全文可得 → (2+0)/4×5 = 2.5）

### 2.5 D5 话题度（0.10）

判定问法：**它是否仍在被当代人主动谈论、改编、引用？**

| 分 | 锚点 |
|---|---|
| 5 | 持续的大众文化再生产（影视/游戏/网络语汇），讨论不依赖教育体系（例：三国演义、山海经、红楼梦） |
| 4 | 周期性进入公共讨论或商业话语（例：孙子兵法在商战语境、庄子在心理/生活方式语境） |
| 3 | 稳定存在于教育与学术议程，公共热度中等（例：史记、诗经） |
| 2 | 主要在专业圈，偶有出圈（例：齐民要术、营造法式） |
| 1 | 基本无当代公共讨论（例：尔雅、释名） |

## 3. 硬门槛（Gate，先过滤再评分）

任何一项不通过即**不进入评分**，避免"分数很高但做不出来"。

| 代号 | 门槛 | 判定方式 |
|---|---|---|
| G1 | 汉文典籍（域外汉文著作如《源氏物语》不在此列，另立专题） | 人工 |
| G2 | 公有领域底本可获取（维基文库优先） | 抓取试跑 |
| G3 | 非纯目录/纯索引；类书、总集须能拆出独立单元 | 人工 |
| G4 | 去重：同书不同注本/选本只入库 1 个代表本（导读可换方法，不换本子） | 查 works 表 |
| G5 | 正文 1 万–200 万字（约束 A） | 抓取后实测 |
| G6 | 不与现有 50 部重复 | 查 works 表 seed_title / ws_title |

## 4. 分档与决策

| 档 | 综合分 | 处置 |
|---|---|---|
| S | ≥ 4.20 | 立即进入抓取+导读管线 |
| A | 3.60–4.19 | 第二批，按性价比排序 |
| B | 3.00–3.59 | 观察池，仅在结构补位需要时入选 |
| C | < 3.00 | 不做 |

**结构校正（不进加权分，人工复核时覆盖机械排序）**：当候选项属于下列缺口且 B 档以上，可上调一档入选——
经部缺三礼与春秋三传、史部缺政书/地理/游记、子部缺佛道与科技、集部缺戏曲与白话小说、蒙学与近世思想近空白。

理由：50 部现有构成是经 12 / 史 10 / 子 18 / 集 10，经部只有五经+四书+小学，三礼与三传全缺，读者无法从"经"这条线走通礼制与史官传统。

---

## 5. 候选池构建原则

- 候选池只从**四部要籍 + 蒙学 + 近世思想**三个来源枚举，不做无限扩张。
- 每部候选必须能说明"补哪个缺口"（`gap` 字段），说不出缺口的不进池。
- 池子目标规模 100–130 部；先全池过 Gate，再对入围者做五维评分。
- 评分必须写依据码（锚点表里的档位），禁止只给数字。

## 7. 复算与治理

### 7.1 复算

```
.venv\Scripts\python.exe pipeline\score_corpus.py --report
```

脚本做三件事：读两张 CSV → 校验（分数区间、依据缺失、Gate 冲突）→ 输出加权排序与分档，同时写出 `data/corpus_scores_ranked.csv`。

### 7.2 可审计要求

- 任一入选书目，必须能在 `corpus_scores.csv` 找到 5 个分数 + 至少 1 条 d3_evidence。
- 任一落选书目，必须能在 `gate_note` 或分数中找到原因。

### 7.3 D3 回填协议（本机网络受限时的处理）

本机当前无法访问 wikidata.org / zh.wikipedia.org（TCP 可连、TLS 后超时），因此 D3 采用两段式：

1. 先按锚点表打"待核验分"（`status=UNVERIFIED`），**不参与排序**；
2. 在可联网环境执行：
   ```
   .venv\Scripts\python.exe pipeline\score_corpus.py --backfill-impact
   ```
   脚本用 `wbsearchentities` 解析 QID，再 `wbgetentities` 批量取 sitelinks 数，按分位映射为 D3 客观分，并写入 `d3_evidence`（含 QID 与 sitelinks 数），状态转 `VERIFIED`。

D3 分位映射（sitelinks → 分）：≥45 → 5；25–44 → 4；12–24 → 3；5–11 → 2；<5 → 1。该阈值在首批 30 部回填后按实际分布重新校准，校准记录写入本文 §8。

**provisional 规则**：D3 为 `UNVERIFIED` 时该行不参与完整加权，改用其余四维（D1/D2/D4/D5，合计权重 0.80）归一化计算临时分，并在输出中标记 `provisional=Y`。这类书目可以进入**执行队列**，但不得据此宣布最终档位——回填后必须重算一次，排名变动 > 3 位者需单独说明。

### 7.4 版本治理

- 模型改动必须升版本号并记录于 §8。
- 权重调整需重算全池并给出排序变动清单（前 10 位变动 > 3 位即视为重大调整，需复核）。
