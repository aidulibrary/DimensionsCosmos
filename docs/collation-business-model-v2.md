# 维点图书馆 · 任务中心商业模式
## 深度解构与重构论证（v2）

> 文档性质：战略论证，不是财务承诺。文中所有"真实价格"均附来源；所有"推演数字"均为**假设模型**，参数写在文末，可复算、可替换。
> 论证起点：上一版（v1）把任务中心设计成"任务市场 + 机构三档订阅"。本版认为该结构在商业上不成立，做拆解并重建。

---

## 0 结论先行

**一句话**：任务中心不是收入中心，是**资产生成器**。它把"一次性工时"炼成"可反复出租的使用权"，收入发生在资产之后，而不是任务之中。

**三句定位**：
1. 内容已经免费，不做内容的守门人，做**可信度的定价者**；
2. 不卖工时，卖年费；不卖阅读权，卖**证据链与授权**；
3. 众包不是廉价劳动力池，是**版税池的分配端**。

**关键数字（含假设）**：

| 指标 | 数值 | 性质 |
|---|---|---|
| 单处缺字全成本 | ¥45.8（初校 ¥41.7 + 抽样审计 ¥4.2） | 计算 |
| 单部书资产化成本（30 处） | ¥2,025 | 计算 |
| 一个书系包（50 部）生产投入 | ¥101,250 | 计算 |
| 书系包年费 / 年托管边际成本 | ¥30,000 / ¥200 | 定价假设 |
| 同包售 10 家年毛利 / 资产复用倍数 | ¥298,000 / 2.94x | 计算 |
| 认证审计毛利率 | 90% | 计算 |
| C 端订阅 LTV/CAC（¥98/年，留存 45%） | 178 / 30 = 5.9 | 计算 |
| 三年收入（基准） | Y1 ¥153 万 → Y3 ¥1,027 万 | 假设模型 |

**必须接受的代价**：这意味着放弃"按单抽佣"的即时现金流，第一年收入会很薄（¥91–250 万区间），换来第二年起资产复用倍数的陡升。若不接受这个时间差，本模式不成立。

## 1 理念—使命—商业的闭环：为什么不能卖阅读权

| 层 | 表述 | 商业推论 |
|---|---|---|
| 理念 | 浇灌自由生长的文明 | 土壤隐喻：土壤不向植物收费，也不挑选植物。→ **凡属"基础阅读"，必须免费且不设关卡** |
| 使命 | 让每一位读者提升认知 | 读者缺的不是"更多文本"（识典已给 4.7 万部），缺的是**"这段话到底对不对、凭什么"**。→ 交付物是**可信**，不是**数量** |
| 商业 | 可持续的被动价值 | "可持续"= 收入不随产能线性增长；"被动"= 资产在前、收入在后。→ **卖使用权，不卖工时** |

三条自我禁令（写进产品，而不是只写进 PPT）：
- 不设阅读门槛：公有领域正文永久免费，不做"解锁全文"；
- 不锁数据：客户可导出 TEI/IIIF，退出可带走（HathiTrust、FromThePage 都承诺可导出，这是机构采购的硬条件）；
- 不卖"更多"，只卖"更可信"。

> 这一条推导出全文的结构：**免费做"读"，收费做"信"。**

### 2.2 五条残酷结论

- **C1 内容端无定价权**：识典以公益资本把 4.7 万部做到免费，任何"阅读订阅"在中国都失去议价基础。
- **C2 机构买的是"权威 + 合规 + 可采购"**：中华经典 6.48–15.2 万的价差不在文本量，而在版本权威与采购合规（单一来源论证）。
- **C3 工具是全球低价品**：€99–449/年、$1,200–3,600/年。工具可以获客，不能养活公司。
- **C4 消费订阅的天花板取决于"刚需"**：Ancestry 靠家谱刚需 + 70 亿份独家文档。古籍阅读不是刚需，**"我祖先/我家乡的那本书"才是**。
- **C5 高价高毛利的只有两处**：**数据资产授权**（买方是新钱：AI 公司、数商、出版、文博）与**认证审计**（买方是怕出错的机构）。

## 3 生态位空缺：可信度的定价权

三方都缺同一件东西：

| 角色 | 现状 | 缺什么 |
|---|---|---|
| 免费库（识典等） | 有文本、有规模 | **证据链**：这一字为何这样定，出自哪本哪卷 |
| 商业库（中华经典等） | 有权威点校 | **可编程性**：封闭界面、不可批量导出、不可训练 |
| AI / 数据买方 | 有钱、有算力 | **可溯源、可评测、可商用授权**的高质量古籍数据 |

**空缺 = 校勘证据层（Provenance + Confidence + License）**

维点的不可替代性不在"收了多少书"，而在这三件事：
1. **可审计**：每一处判定可回溯到版本、卷次、字位、出处（本项目已有 `#ch-{id}:b{bi}:k{kth}` 字位锚点体系，这是稀缺基础设施）；
2. **可评测**：有对抗样本与基准集（49 处 A/B/C 分级就是天然的 benchmark 雏形）；
3. **可授权**：数据带清晰 license，能进商用与训练。

> 一句话：**别人卖"文本"，维点卖"文本的信用"**。信用可以按年出租，文本不能。

## 4 "可持续的被动价值"：定义、判据与伪命题

### 4.1 三个流行误解（先破）

| 误解 | 为什么错 |
|---|---|
| "订阅就是被动收入" | 订阅要持续服务、持续获客、持续留存。留存 45% 的订阅，本质是"跑步机" |
| "众包就是免费劳动力" | 无偿供给不可持续；识典用公益资本 + 学分激励才跑通，商业公司照抄会崩 |
| "年费就是躺赚" | 机构年费每年要过采购论证、要比价、要续约答辩。躺不了 |

### 4.2 可操作的判据

定义**被动度**：

```
P = 1 − (边际交付成本 / 边际收入)
```

四个必要条件（缺一即伪被动）：

| 准则 | 含义 | 检验问题 |
|---|---|---|
| 可预付 | 客户为"一段时间的使用权"付费，不为工时 | 客户能否在交付前付款？ |
| 可复用 | 同一资产卖给 N 个客户，边际成本≈托管费 | 第 2 个客户要再花多少钱？ |
| 可审计 | 有第三方可验证的质量凭证，采购才敢续约 | 客户能否拿我们的数据去答辩？ |
| 抗替代 | 免费品无法覆盖（因为它缺证据链与授权） | 识典明天全免费，我们还剩什么？ |

### 4.3 五引擎的被动度打分

| 引擎 | 边际交付成本占比 | 被动度 P | 续约驱动 |
|---|---|---|---|
| E1 认知订阅（C 端） | ~15%（客服/内容更新） | 0.85 | 使用频次与"查得到" |
| E2 研勘席位（机构） | ~10% | 0.90 | 工作流沉没成本 |
| E3 数据授权（书系包/API） | ~1%（托管） | **0.99** | 数据进入客户管线后不可拆 |
| E4 认证审计 | ~10%（1 人日/家） | 0.90 | 采购合规刚需 |
| E5 版税池分账 | 变动成本本身 | — | 不属于收入引擎，属于**成本结构** |

## 5 五引擎重构（替代 v1 的"三档订阅 + 抽佣"）

### E1 认知订阅 · C 端 ¥98/年
- **交付物**：全库阅读（本来就免费）+ 可查询的校勘证据、异体字/避讳/官职检索、个人书架与导出。
- **为什么是 98 而不是 3.9/篇**：单篇付费把用户训练成"比价者"，且与免费库正面冲突；年费把关系变成"常来"。LTV/CAC = 5.9（留存 45% 假设）。
- **风险**：中国古籍 C 端付费转化极低。**这是全模型最脆弱的一环**，Y3 若做到 4.5 万付费用户已属乐观。

### E2 研勘席位 · 机构 ¥68,000/年（含 5 席）
- **交付物**：校勘工作台、私有任务池、TEI/IIIF 导出、审计报告。
- **定价锚**：中华经典古籍库 6.48 万（陕西理工）——同一预算科目，同一采购流程，价格带内不引发比价。
- **差异**：他们卖"书"，我们卖"可编程的校勘数据 + 协作产能"。

### E3 数据授权 · 书系包 ¥30,000/年（50 部）
- **交付物**：结构化异文、校勘记、版本谱系、置信度、字位锚点、license 元数据。
- **经济性**：生产投入 ¥101,250/包；售 10 家 → 年毛利 ¥298,000，复用倍数 2.94x；售 20 家 → 5.89x。
- **纪律**：**复用倍数 < 2 之前不扩产**，先卖同一包。

### E4 认证与审计 · ¥40,000/年/机构
- **交付物**：校勘质量认证（抽样审计报告、α 一致性、错误率区间）、可公示的认证标识。
- **经济性**：成本 ¥4,000（1 人日），毛利 **90%**。
- **为什么买方会买**：高校/出版社/数据库商需要向采购方与评审证明"我的古籍数据是干净的"。这是**合规支出**，不是内容支出。
- **这是最快见钱、最高毛利、最不依赖流量的引擎。**

### E5 版税池 · 贡献者分成 20–30%
- 不是收入引擎，是**成本结构改造**：把"固定人力成本"变成"随资产收入浮动"。
- 结算依据是"该处判定被采用且通过审计"，不是"提交过"。
- 这一条同时解决了 v1 的"积分无价值"问题：积分的兑付物是**真实现金流的分成权**。

> **对 v1 的处置**：删除"任务市场抽佣"作为收入项，任务中心降为**结算管道 + 资产生产线**，不背收入指标。

## 9 风险与反脆弱

| 风险 | 触发信号 | 应对 |
|---|---|---|
| 免费替代（识典继续扩张） | 识典上线"校勘/异文对照" | 不与内容竞争；把证据层做成**可被免费库调用的 API**（成为他们的供应商，而非对手） |
